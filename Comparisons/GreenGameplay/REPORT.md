# Green в основной игре

Подойди к NPC, нажми **E**, выбери **Kind → Green animations**. Справа есть 11 позиций каталога, отдельные действия, клипы пальцев и скорости для каждой кисти, список парных пресетов, Stop и Restart. ЛКМ и ПКМ над NPC работают как удержание соответствующей кистью. Для отдельных действий можно использовать кнопки Contact и Release.

## Таблица и выбор клипов

| Контакт | Переходы тела |
| --- | --- |
| Грудь | `Idle → M_Touch → M_Idle → Idle` |
| Пах | `Idle → A_Touch → A_Idle → Idle` |
| Ягодицы | `Idle → S_Touch → S_Idle → Idle` |
| Бок, живот, бедро, рука, макушка, ступня и щиколотка | Исходный `Idle` выбранной позиции и локальные реакции |

[green_interactions.json](../../KksPrototype/Content/green_interactions.json) задаёт точные ID состояний, источники, приоритеты, реакции и привязки к клику. Поле `positions` предназначено для переопределений с ключом ID позиции и действия. Полный путь выбора идёт от ID позиции и ID состояния к записи `game` или `studio` из `h_caressing.json`, затем к указанному KMA. При подходе тело остаётся в исходной анимации. Переход Touch включается после подтверждённого попадания в меш. После окончания Touch включается удержание или возврат.

На полном слое играет один исходный клип. Приоритет принадлежит подтверждённому контакту с высшим значением таблицы. Вторая кисть сохраняет свою фазу и вносит локальную реакцию. Одинаковые маршруты используют текущий клип без повторного старта при смене ведущей руки. Смешивание при переходах занимает около 0,3 секунды.

Для новых действий используются пресеты и покостное смешивание из F7. Макушка воздействует на голову и взгляд, бока на корпус и плечи, кисть на плечо соответствующей стороны. Для стоп и щиколоток используются исходные кривые LegL1/2 и LegR1/2 в локальной реакции. Зоны привязаны к текущему скелету, пальцы используют существующие KMA. Три прежних действия и JSON v1/v2 получают назначения из общей библиотеки. Мимика берётся из набора исходных лицевых пресетов с выбором семейства M, A или S и сглаженным возвратом после отпускания.

## Ограничения

Мебель и привязки MotionIK из Unity пока отдельно не переносятся. В комнате позы для стула или стола проигрывают оригинальный клип и могут требовать опоры. Покрытие мимикой зависит от совместимости меша карточки с таблицами F7. Проигрывание в основной комнате использует варианты под прикосновения рук. Остальные исходные состояния доступны в F7.
