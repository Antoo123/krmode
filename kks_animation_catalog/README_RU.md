# Каталог анимаций Koikatsu Sunshine из оригинального list.zip

Источники — только переданные оригинальные файлы `list/*.unity3d` и ранее переданная
`Assembly-CSharp.dll`. Никаких догадок о содержимом AssetBundle.

## Что здесь есть

- **150 уникальных записей анимаций** после объединения оригинальных таблиц
  (в исходниках **267** записей с учётом двух версий/дополнений).
- **11 зелёных сцен** из `AnimationInfo_00`; `green_caress.csv`.
- **19 парных записей стоя** по категории `8` или японскому слову `立ち`.
  Важно: это эвристика отбора стоячих, а не утверждение о POV.
- **26 записей зон касания** `aibulayer_00..05` из `HandCtrl`.
- **234 правил доступности касаний** `aibuaction_*`.
- **13 описаний предметов касания** `AibuItemObject`, в том числе
  `p_handL/R`, `p_fingerL/R`, `p_tang` (язык), вибраторы и другие предметы.
- **27 привязок иконок** `AibuIconTexture`.
- **3 пресета смещения/поворота** из `MoveOffsetData`.

`*.csv` сохранены в UTF-8 с BOM (японский и русский текст открываются в Excel).
`*.json` сохраняют исходные названия и исходные структуры Unity без потерь.

## Как оригинальная игра сопоставляет персонажей

1. `HSceneProc.CreateAllAnimationList` загружает `AnimationInfo_XX` из `h/list/*.unity3d`.
   Пара определяется **одной строкой `AnimationInfoData.Param`** по `(group, id)`.
2. `pathMaleBase` + `paramMale.path` — базовый и сменный аниматор мужчины,
   `pathFemaleBase` + `paramFemale.path` — женщины. Строка уже связывает их.
3. `HSceneProc.ChangeAnimator` загружает нужные контроллеры одновременно.
   `HActionBase.SetPlay` запускает у обоих одноимённое состояние через
   `ChaControl.syncPlay(state, 0, 0.0)`.
4. `HSceneProc.SetLocalPosition` берёт `lstCategory[].fileMove`, читает
   `MoveOffsetData.Param.pos/rot` и применяет ОБЩУЮ позицию/поворот корней.
   Не следует считать эти координаты взаимным отступом между персонажами.
   Совпадение тел обеспечивают сами согласованные анимации и `MotionIK`.

## Зелёная сцена и реальные действия касания

- `AnimationInfo_00` содержит 11 позиций с базовым женским контроллером
  `kha_f_base` и `kha_f_00 ... kha_f_10`; отдельного мужского контроллера в этих
  строках нет. Управление касаниями выполняет `HandCtrl`.
- Например, `id=0`, `立ち愛撫`, «Ласки стоя»: женский контроллер `kha_f_00`
  берётся из `h/anim/female/00_01_00.unity3d`. С дополнением `71` базовый
  контроллер `kha_f_base` берётся из **`h/anim/female/00_71_00.unity3d`**,
  а не из того же файла, что сменный контроллер.
- `HandCtrl.LoadLayerInfo` читает `aibulayer_00..05` и сопоставляет действия
  с зонами: `00` левая грудь, `01` правая грудь, `02` пах/гениталии,
  `03` анальная область, `04` левая ягодица, `05` правая ягодица.
  Названия частей тела подтверждаются `HandCtrl.Init` (`cf_d_bust01_L`,
  `cf_d_bust01_R`, `cf_d_kokan`, `cf_d_ana`, `cf_d_siri01_L`, `cf_d_siri01_R`).
- В `aibu_touch_layers.csv` каждая строка — конкретное действие внутри зоны:
  `icon_id`, `icon_sprite`, `object_assets`, `parent_bones`, `click_action`,
  `drag_action`, а также три варианта
  `variation_*_front_body` / `back_body`. Числа — **ID слоя тела/предмета**, а
  не названия AnimationClip и не универсальные ID типов поглаживания.
- В `aibu_motion_permissions.csv` значения `0/1` показывают, на каких частях
  тела разрешены касания для состояний `Idle`, `M_Touch`, `M_Idle`, ...
  Например, основное `aibuaction_kha_base` разрешает все шесть зон в
  обычных состояниях, но выключает их в `Front_Dislikes` и `Back_Dislikes`.
- `aibu_tools.csv` позволяет раскрыть `idObjects`, например `0→p_handL`,
  `1→p_handR`, `2→p_fingerL`, `3→p_fingerR`, `4→p_tang`.

## Как перейти к самим клипам

`list.zip` содержит **реестр и настройки**, но не сами клипы.
Имена вроде `khh_m_33` и `khh_f_33` — ссылки на контроллеры.
Чтобы проверить конкретные AnimationClip и state machine, нужны
`abdata/h/anim/male/*.unity3d` и `abdata/h/anim/female/*.unity3d`.
Чтобы посмотреть настройки `MotionIK`, понадобятся соответствующие H/IK
AssetBundle. Наличие `nameCamera` не означает подтверждённый POV.

## Ограничения версии

`AnimationInfo_00` есть и в `list/01.unity3d`, и в `list/71.unity3d`;
все 11 строк отличаются ссылкой `pathFemaleBase`. База `71` также добавляет
новые строки в `aibulayer_00, 01, 02`. В `*_effective` поверх базовых записей
применены записи из `71`, поскольку DLL сортирует `HFlag.lstABName` перед
загрузкой и перезаписывает совпадающие `(group,id)` при последующей загрузке.
`*_raw` и `animations_all_versions.csv` сохраняют обе версии для проверки.
